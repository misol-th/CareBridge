# CareBridge — English Prototype

Open `index.html` in a modern browser, or upload it to the root of a GitHub repository and enable GitHub Pages.

Features: clickable dashboard cards and alerts, inventory add/edit/delete, delivery calendar, rule-based demo AI assistant, manual emergency notice log, editable account/workspace profile, browser-local storage, and JSON export.

Limitations: this is a front-end demonstration. The assistant is rule-based, not a trained AI model. It does not connect to hospital systems, suppliers, official emergency services, or live outbreak feeds. Notices are manual/demo entries and must be verified with official authorities. It is not for clinical decisions. Use sample data only; do not enter patient or confidential hospital information.
